A modular content-based hybrid recommender system with an end-to-end pipeline for data processing, 
candidate generation, feature engineering, retrieval, and ranking.

Current progress:

•	ETL pipeline implemented

•	User-item interaction and ranking feature engineering implemented

•	Multiple candidate-generation strategies implemented

•	Content embeddings generated using Sentence Transformers

•	FAISS vector-search infrastructure implemented

•	Training, validation, and test candidate splits implemented

•	Candidate hardness scoring and negative sampling implemented

•	Logistic Regression ranking baseline implemented

•	Ranking evaluation implemented using: AUC, Precision@K, Recall@K, NDCG@K

•	Experiments comparing training on the original imbalanced dataset and negatively sampled data completed

•	Baseline vs Neural Network ranking experiments completed

•	Model comparison and visualization implemented
